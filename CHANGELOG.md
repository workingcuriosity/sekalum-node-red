# Changelog

All notable changes to `@workingcuriosity/node-red-sekalum` are documented
here. The project follows Semantic Versioning.

## [0.1.0] - 2026-09-12

Initial public baseline.

- Added Discover and Resolve Node-RED nodes for the Sekalum Consumer API.
- Added secure Node-RED credential storage for the Consumer API token.
- Added token-free example flow and local mock-server test suite.
- Added canonical Sekalum node icon.
